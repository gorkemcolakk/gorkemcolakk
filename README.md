**Tech Stack:** Python • Streamlit • REST APIs • LLMs (Qwen, DeepSeek) • Agile/Scrum

## 💡 Hint.ai - AI Learning Companion (SaaS)
A full-stack SaaS platform providing step-by-step learning hints through a custom LLM Gateway with provider abstraction. Features strict KVKK compliance with advanced PII masking before LLM processing.
**Tech Stack:** FastAPI • Python 3.12 • SQLAlchemy 2 • PostgreSQL • Redis • Docker

## ⚕️ Aura Health - AI-Powered Personal Assistant
A comprehensive mobile health ecosystem integrating water tracking, sleep analytics, and exact medication alarms. Features an AI Health Coach with voice interaction (STT & TTS) and biometric authentication.
**Tech Stack:** Flutter • Dart • Firebase • Cloud Firestore • Google Gemini 2.5 Flash

---

## 🎫 Eventix - Smart Ticketing Ecosystem
A full-stack event management platform featuring a role-based security architecture, virtual POS integration, and HMAC-SHA256 signed dynamic QR e-ticket validation.
**Tech Stack:** Python • Flask • SQLite • Turso Cloud • JWT

---

## 📈 GOBA INVEST - Financial Analytics Platform
An AI-powered forecasting system projecting 2-year currency trends using Meta Prophet. Includes a thread-safe background daemon (RateCache) for zero-latency live market data fetching.
**Tech Stack:** Python • Flask • Meta Prophet • Plotly • Docker
